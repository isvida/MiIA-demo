# Informe de incidencias

Cuando te pidan un informe de incidencias, escríbelo en `informe.md` con esta estructura exacta:

1. Un título `# Informe de incidencias`.
2. Una tabla Markdown con columnas: `ID | Servicio | Prioridad | Resumen (máx. 15 palabras)`.
   Ordena las filas de prioridad **alta** a **baja**.
3. Una sección `## Acciones recomendadas` con una viñeta por cada incidencia de prioridad alta o media.
4. No inventes datos: si algo no consta en la incidencia, escribe "no consta".
